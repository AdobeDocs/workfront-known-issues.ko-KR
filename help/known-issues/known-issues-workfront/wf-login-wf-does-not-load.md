# 로그인: 로그인 후 Workfront이 로드되지 않음

>[!NOTE]
>
>이 문제는 2026년 2월 19일에 수정되었습니다.

사용자가 Workfront에 로그인할 때 Workfront이 로드되지 않습니다. 페이지를 새로 고치면 Workfront이 예상대로 로드됩니다.

**해결 방법**

페이지를 새로 고칩니다.

_2026년 1월 14일에 처음 보고되었습니다._
