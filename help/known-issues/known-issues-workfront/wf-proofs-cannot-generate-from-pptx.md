# 교정쇄: PowerPoint 파일에서 교정쇄를 생성할 수 없음

사용자가 PowerPoint에서 교정쇄를 생성하려고 할 때 교정쇄가 생성되지 않고 오류 메시지가 표시됩니다.

**해결 방법**

PowerPoint 파일을 PDF으로 내보낸 다음 PDF에서 교정쇄를 만듭니다.
