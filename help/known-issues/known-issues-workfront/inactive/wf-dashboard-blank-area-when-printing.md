# 대시보드: 대시보드를 PDF로 인쇄할 때 큰 공백 여백이 있음

<!--Article by request-->

사용자가 가로 방향을 사용하여 대시보드를 PDF로 인쇄하면 PDF 오른쪽에 큰 공백 여백이 표시됩니다.

**해결 방법**

세로 모드로 인쇄하면 여백이 올바르게 표시됩니다.
