# 사용자: 사용자 페이지를 여는 중 오류 발생

>[!NOTE]
>
>이 문제는 2025년 12월 12일에 해결되었습니다.

사용자가 메인 메뉴에서 사용자 페이지를 열려고 할 때 페이지가 열리지 않고 다음과 같은 메시지가 표시됩니다.

“오류가 발생했으며 문제를 해결하기 위해 노력 중입니다. 작업을 계속하려면 이 브라우저 페이지를 새로 고침해 보십시오.”

_2025년 12월 8일에 처음 보고되었습니다._
