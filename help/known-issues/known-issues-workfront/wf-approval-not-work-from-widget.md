# 승인: 홈의 내 승인 위젯에서 문서를 승인할 수 없음

사용자가 홈의 내 승인 위젯에서 문서를 승인하려고 하면 위젯에서 문서가 사라집니다. 단, 문서가 승인되지 않으며 사용자가 페이지를 새로 고치면 문서가 위젯에 다시 나타납니다.
